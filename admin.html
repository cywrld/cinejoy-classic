One-time setup needed

Connect your Supabase project.

This admin uses Supabase Auth, Postgres, and Storage. It is not using local browser-only authentication or catalog persistence.

  1. Follow the Supabase setup guide to create the tables, policies, storage bucket, and first admin account.
  2. Set your project's URL and public anon key in supabase-config.js.
  3. Host this folder over HTTPS. Never place a service-role key in any browser file.
